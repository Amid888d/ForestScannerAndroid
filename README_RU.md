# Forest Scanner (Android)

Приложение для учебного прототипа: сканирует Bluetooth Low Energy (BLE), показывает имя/адрес/RSSI найденных устройств, выводит GPS-координаты самого телефона и подаёт звуковые сигналы чаще при более сильном RSSI.

## Важно
- Видит только устройства, которые реально рекламируют BLE. Обычный Bluetooth и фотоловушки без BLE-рекламы не обнаруживаются.
- RSSI — грубый показатель уровня сигнала, а не точное расстояние.
- GPS показывает положение телефона, не найденного устройства.

## Сборка APK через GitHub Actions
1. Создайте новый GitHub-репозиторий `ForestScannerAndroid`.
2. Загрузите содержимое этого архива в корень репозитория (включая скрытую папку `.github`).
3. Откройте вкладку Actions и дождитесь завершения `Build Android APK`.
4. В завершённом запуске скачайте artifact `ForestScanner-debug-apk`; внутри будет `app-debug.apk`.
5. Перенесите APK на Android, откройте его и разрешите установку из этого источника.
